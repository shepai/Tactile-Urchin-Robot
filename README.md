# Tactile-Urchin-Robot
Repo based on the <a href="https://github.com/shepai/tactile-ball-robot">ball robot gym</a>, but makes use of a sea urchin inspired robot instead. The ball is made of a Icosahedron shape of interconnected tactile triangular sensors.
These sensors are based on the <a href="https://github.com/shepai/TacSheet">TacSheet repo</a>. 

![Urchin simulator](https://raw.githubusercontent.com/shepai/Tactile-Urchin-Robot/refs/heads/main/assets/urchin.png)

## Installation 
Navigate to the folder path of Tactile-Urchin-robot/urchin/ and use the command
```[bash]
pip install -e .
```
